# Daily Workflow

# Początek dnia

## 1. Operator uruchamia system
System ładuje:
- layout magazynu
- gridy
- doki

---

## 2. Import LP1
Operator importuje:
- godziny przyjazdu sklepów

---

## 3. Import LP2
Operator importuje:
- godziny wydań
- ilości
- LP

---

## 4. Planner uruchamia obliczenia
System:
- łączy LP1 i LP2
- analizuje czasy
- rozdziela sklepy po dokach
- przydziela miejsca

---

# W trakcie dnia

## 5. Monitoring magazynu
Na ekranie widoczne są:
- sklepy
- doki
- statusy
- zajętość miejsc

---

## 6. Przypomnienia
System:
- pokazuje alerty
- odczytuje komunikaty głosowe
- informuje o wydaniach

---

## 7. Automatyczne zwalnianie miejsc
Po godzinie wydania:
- sklep znika
- miejsce zostaje zwolnione

---

# Koniec dnia

## 8. Nowy dzień pracy
Operator:
- importuje nowe LP1
- importuje nowe LP2

Layout magazynu pozostaje bez zmian.
