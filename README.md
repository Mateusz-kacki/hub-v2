# HUB L

System planowania magazynu i doków załadunkowych.

## Główne funkcje
- import LP1 (przyjazdy sklepów)
- import LP2 (wydania sklepów)
- automatyczne rozmieszczanie sklepów
- kontrola kolizji czasowych
- wizualny plan magazynu
- zarządzanie dokami 16/17/18

## Technologie
- React
- FastAPI
- SQLite/PostgreSQL
